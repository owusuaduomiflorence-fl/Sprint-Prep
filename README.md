# Women Techsters Sprint Preparation (`sprint-prep`)

Welcome to my **Women Techsters Sprint Preparation** repository! This repository serves as a centralized workspace for all practical modules, exercises, and foundational projects completed during the sprint preparation track.

## Repository Overview

This workspace contains three core module directories:

- **`profile-page/`**: A responsive, interactive developer profile card built using HTML5, CSS3, and JavaScript DOM manipulation.
- **`todo-app/`**: Workspace dedicated to building an interactive task management web application.
- **`practice/`**: Terminal automation scripts, Node.js environment test runs, and core JavaScript fundamentals.

## Tools & Technologies Used

- **Version Control:** Git & GitHub
- **Frontend Core:** HTML5, CSS3 (Flexbox & Box Model), Modern JavaScript (ES6+)
- **Runtime Environment:** Node.js
- **Editor & CLI:** Visual Studio Code & PowerShell Terminal

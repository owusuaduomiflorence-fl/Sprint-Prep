# Personal Developer Profile Page

A clean, responsive, and interactive personal profile card web application built with vanilla HTML, CSS, and JavaScript. This project showcases web layout fundamentals, modern CSS centering techniques, and JavaScript DOM manipulation.

## 🚀 Features

- **Responsive Design:** Formatted layout optimized for all screen sizes.
- **Interactive Greeting:** Integrated JavaScript DOM event handling with browser environment compatibility.
- **Clean Styling:** Styled avatar, custom typography, and responsive call-to-action buttons.
- **Direct GitHub Link:** Quick navigation link to GitHub project repositories.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure (`<main>`, `<header>`, etc.)
- **CSS3:** Flexbox layout, CSS box model, custom styling, and media handling
- **JavaScript (ES6):** DOM selection and event listeners
- **Node.js:** Backend script execution testing environment

## 📂 Project Structure

profile-page/
